      What the doc can look like
      • Word (.docx), Excel (.xlsx, every tab), CSV, text or Markdown. From Google Docs use File, Download, Microsoft Word (.docx); from Sheets use .xlsx. Or use Paste text.
      • Ad groups can be headings (Ad Group 1: Managed IT or just Managed IT), table rows, table columns, spreadsheet tabs or plain lines before a Keywords list.
      • Ad text can be lists, tables with a character-count column, numbered lines (Headline 3: ...) or one mixed Ad copy list.
      • Settings the tool picks up: Final URL, Locations: Austin, TX, Daily budget: 50 or Monthly budget: 1,500, Bidding: Maximize conversions, Match type: Phrase, Path 1, Start date.
      • Keywords written as [keyword], "keyword" or keyword (broad) keep that match type; -keyword is a negative.
      • Anything the tool cannot place shows up in the import report, where you can teach it.

      Export

      Ready

          Import in Google Ads Editor

          1. Open the account in Ads Editor and click Get recent changes.
          2. Go to Account > Import > From file and pick the CSV. If you copied instead, use Paste text.
          3. Check the preview, then Finish and review changes and Keep.
          4. If Editor flags EU political ads on the new campaigns, select them and set it to No.
          5. Locations without an ID are matched by name. Check them in the Locations tab.
          6. Review, then Post. Campaigns arrive with the status you picked above.
